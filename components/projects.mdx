The Projects page presents the developer's portfolio work through the lens of a retro game library. Each project is rendered as a stylized game cartridge card — complete with a glowing title, arcade-style metadata fields (`GENRE:` and `PLAYERS:`), and a description block. When a visitor hovers over a card, hidden action buttons slide into view: **RUN DEMO** to open a live deployment and **SOURCE** to navigate to the repository. All card data is pulled from the `projects` array in `data/mockData.js`, so adding or updating a project requires only a data change — no JSX edits needed.

## Route

| Property | Value |
|---|---|
| Path | `/projects` |
| File (compiled) | `assets/main.js` — `ProjectsPage` component |
| Data export | `projects` (exported as `p` from `mockData.js`) |
| Theme colors | Per-project `color` field — `purple` · `lime` · `magenta` · `cyan` |

## What It Displays

The page renders a responsive CSS Grid of project cards. On mobile the grid is a single column; on desktop it expands to two columns. A section heading introduces the screen in arcade style.

Each card shows:

- **Title** — rendered with a neon glow in the project's accent color
- **Year** — displayed at the top right of the card in dim monospace
- **GENRE** — a short genre tag (e.g., `WEB APP`, `TOOL`, `GAME`)
- **PLAYERS** — a player count string (e.g., `1P`, `MULTI`)
- **Description** — a two-to-three sentence summary of the project
- **RUN DEMO button** — links to the live URL; hidden by default, revealed on hover
- **SOURCE button** — links to the repo URL; hidden by default, revealed on hover

## Animations

Cards animate in using Framer Motion's `whileInView` trigger. Each card starts at opacity `0` with a downward `y` offset and transitions to full opacity and natural position as it enters the viewport.

```js
// Approximate per-card animation variant
const cardVariants = {
  hidden: { opacity: 0, y: 40 },
  visible: {
    opacity: 1,
    y: 0,
    transition: { duration: 0.5, ease: "easeOut" },
  },
};
```

The hover-reveal action buttons use a CSS transition on `opacity` and `translateY`, toggled by the parent card's `:hover` pseudo-state (via Tailwind's `group` + `group-hover` utilities).

<Note>
  The `whileInView` trigger fires **once** — cards do not re-animate when they scroll back into view after leaving. This is controlled by the `once: true` option passed to the Framer Motion `viewport` prop.
</Note>

## Data Schema

Each project object in the `projects` array must conform to the following shape:

```ts
type Project = {
  id: string;          // Unique identifier, used as React key
  title: string;       // Display name of the project
  year: number;        // Release or completion year
  genre: string;       // Short genre tag shown as "GENRE: <value>"
  players: string;     // Player count shown as "PLAYERS: <value>"
  description: string; // Short prose summary of the project
  color: "purple" | "lime" | "magenta" | "cyan"; // Accent color for glow + border
  demoUrl: string;     // URL opened by the RUN DEMO button
  sourceUrl: string;   // URL opened by the SOURCE button
};
```

### Field Reference

| Field | Type | Displayed As | Notes |
|---|---|---|---|
| `id` | `string` | Not displayed | Used as React list key |
| `title` | `string` | Card heading with neon glow | Keep under 40 chars for layout |
| `year` | `number` | Top-right of card | Four-digit year |
| `genre` | `string` | `GENRE: <value>` | Use all-caps arcade style, e.g. `WEB APP` |
| `players` | `string` | `PLAYERS: <value>` | E.g. `1P`, `MULTI`, `CO-OP` |
| `description` | `string` | Body text of card | 2–3 sentences recommended |
| `color` | `string` | Glow + border accent | Must be one of four valid tokens |
| `demoUrl` | `string` | RUN DEMO button href | Full absolute URL |
| `sourceUrl` | `string` | SOURCE button href | Full absolute URL |

## Customization

**Adding a new project**

Open `data/mockData.js` and append a new object to the `projects` array:

```js
// data/mockData.js
export const projects = [
  // ... existing entries
  {
    id: "my-new-project",
    title: "Pixel Weather App",
    year: 2025,
    genre: "WEB APP",
    players: "1P",
    description:
      "A retro-styled weather dashboard pulling live forecast data. Features animated pixel-art weather icons and a 7-day outlook panel.",
    color: "cyan",
    demoUrl: "https://weather.example.com",
    sourceUrl: "https://github.com/you/pixel-weather",
  },
];
```

**Changing accent colors**

Set the `color` field to any of the four supported token values: `"purple"`, `"lime"`, `"magenta"`, or `"cyan"`. The card border, title glow, and button highlight all derive from this single field.

**Hiding the SOURCE or RUN DEMO button**

If a project has no live demo or no public repository, set the corresponding URL to an empty string (`""`). The component checks for a truthy value before rendering the button.

<Tip>
  Keep the `genre` and `players` values short — they render in `VT323` pixel font at a fixed size. Labels longer than ~10 characters may overflow on mobile screens. See [Typography](/reference/typography) for font size reference.
</Tip>
